# 割り勘電卓（インストール可能なWebアプリ）

## 公開方法
このフォルダ内のファイル一式を、HTTPS対応のWebサーバーに同じ構成でアップロードしてください。
例：GitHub Pages、Netlify、Cloudflare Pages など。

## インストール方法（Android / Chrome）
1. 公開したURLをChromeで開きます。
2. メニュー（︙）から「アプリをインストール」または「ホーム画面に追加」を選びます。
3. 追加後はホーム画面からアプリのように起動できます。

## 注意
- Service Workerによるオフライン利用には、HTTPS（または開発用のlocalhost）が必要です。
- HTMLファイルを端末内で直接開いただけでは、インストール機能は有効になりません。
